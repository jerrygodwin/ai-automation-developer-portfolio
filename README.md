# Jerry Bogban — Software & Automation Portfolio

Source code for the live portfolio: https://jerry-ai-automation-portfolio-mannova.vercel.app

## Overview

A responsive, single-page portfolio presenting work across software development, workflow automation, API integrations, and AI-assisted systems.

## Selected projects

- **Crestwell Realty** — property discovery and viewing-request experience with workflow automation and n8n integration.
- **NECA ICT Academy** — academy-management platform development.
- **SkyKids One** — school-management application development.
- **Divine Life Hospital — AI Support Design** — documented RAG assistant concept with safety boundaries and review requirements.
- **VicinityHub** — community-platform development with authentication and data-access controls.
- **AI Lead Follow-up Workflow** — n8n workflow design for structured lead follow-up.

Project descriptions distinguish implementation work, design/prototype work, and features that still require validation. They do not claim that every integration is fully production-verified.

## Technology and capabilities

HTML, CSS, JavaScript, Next.js, React, TypeScript, n8n, REST APIs, webhooks, Supabase, PostgreSQL, Git, GitHub, Claude Code, and Codex.

## Run locally

This repository contains the static HTML source for the deployed portfolio.

```bash
git clone https://github.com/jerrygodwin/ai-automation-developer-portfolio.git
cd ai-automation-developer-portfolio
```

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy

The current version is a static site. Import this repository into Vercel, use the repository root, and leave the build command empty. No framework preset is required.
